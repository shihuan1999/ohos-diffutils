结论速览（先给答案）

V100 是什么：进迭时空（SpacemiT）推出的首款面向服务器市场的 RISC-V 芯片，属 V 系列旗舰，基于中科院“香山·昆明湖”开源处理器核，实测 SPEC CPU2006 约 16.5 分/GHz，以 2U 整机形态完成工程化落地。它最大的意义不是“跑分之王”，而是把 RISC-V 从“PPT 性能/低端 IoT”推进到“可交付的服务器整机”。

我的判断（分层）：

  • 就“RISC-V 阵营内部”而言，我最看好的是“香山系”的落地，而 V100 是其中通用算力侧的代表。需要先纠正一个常见误读：V100 并非首个量产的 RISC-V 服务器 CPU——蓝芯算力 LX500（同样基于香山·昆明湖）已随联想问天 WR5219 G5 先行量产。V100 的优势在“通用算力密度 + 端云全栈 + 自研 IP 广度”，而非量产领先。
  • 就“通用服务器/云计算主战场”而言，1–2 年内我更看好 ARM（尤其国产 ARM 鲲鹏/飞腾 + 云厂商 Graviton 类）与 x86。生态成熟度、软件兼容性、TCO 仍有明显代差；V100 当前更适合“边缘/信创/特定 AI 推理”场景，而非直接替换 EPYC/Xeon。
  • 就“纯性能天花板”而言，RISC-V 阵营里我更看好 Tenstorrent Ascalon、SiFive P870-D、Ventana Veyron V2 这类高端 IP。V100 的 16.5 分/GHz 已属 RISC-V 第一梯队，但单核绝对性能仍落后这几家。

1. V100 是什么：发布背景与规格

1.1 发布背景

“第六届 RISC-V 中国峰会（RISC-V Summit China 2026）”于 2026 年 10 月 18–20 日在深圳会展中心（福田）举行，大会主论坛定于 10 月 19 日，进迭时空创始人兼 CEO 陈志坚发表主题演讲《从端到云：RISC-V 的下一程》。[cite:1][cite:2] 这一时间点与您提到的“今天发布”吻合。

需要说明的是：V100 并非“横空出世”。公开时间线显示它已酝酿一年以上：

  • 2025-01：进迭时空对外披露正在研发服务器级 RISC-V 芯片 V100，基于自研 X100 核，支持虚拟化、IOMMU 与安全特性，SPECINT2006 超过 9 分/GHz。[cite:3]
  • 2025-07：RISC-V 中国峰会期间，产业链消息称 V100（64 核）目标当年 Q4 量产；同期开芯院宣布“昆明湖”IP 首批量产客户交付，进迭时空基于“昆明湖”自研 X200，并推进首款服务器芯片（集成“昆明湖”核）流片。[cite:4][cite:5]
  • 2026-01：有报道称 V100 已在 1 月“发布/亮相”，并给出 64 核、2.5GHz、约 32 TOPS(INT8) 等口径（第三方媒体，待官方口径确认）。[cite:6]
  • 2026-03：中关村论坛上，“香山+如意”发布，现场展出 V100 服务器，香山方称 V100 基于“昆明湖”核设计并流片，实测单核 SPEC2006 16.5 分/GHz。[cite:7]
  • 2026-08：进迭时空在公开演讲中表示“V100 已流片回来，将择机正式发布；V200 在研发中”。[cite:8]
核实提示：截至本报告数据截止日，未见可交叉验证的“V100 于 10 月 19 日正式发布”的官方通稿被检索到（峰会主论坛当日进行中，内容可能尚未被索引）。上文规格为公开披露口径，最终以进迭时空官方发布为准；其中“64 核”等参数目前主要来自第三方媒体，存在待确认空间。

1.3 一处重要的口径冲突（必须说明）

关于 V100 的 CPU 核来源，公开信息存在两条链路：

  • 链路 A（早期，2025）：V100 使用进迭时空自研 X100 核——X100 基于开源项目 openc910 二次开发，12 级流水线、乱序四发射、RVA23、支持 64 核互联、2.5GHz@TSMC 12nm、SPEC2006 >9 分/GHz。[cite:3][cite:9]
  • 链路 B（2026，更晚更权威）：V100 基于中科院 香山·昆明湖开源核（对标 ARM Neoverse N2），由合作伙伴进迭时空设计并流片，实测 16.5 分/GHz。[cite:7][cite:10]

两条链路并非完全互斥——可能是“早期规划用 X100、后期旗舰改用/融合昆明湖”的演进。本报告以 链路 B（香山·昆明湖） 为分析基线，因为它是更晚、更权威（中科院/香山官方/人民网/中国科学报）且被多方一致引用的口径。

1.4 V100 的战略含义

它不是一次孤立的芯片发布，而是三件事汇合：

  • 开源 IP 成熟：香山“昆明湖”完成产品级验证（近 100% 覆盖率）并交付量产客户，开源高性能核首次真正进入商业芯片。[cite:7]
  • RVA23 落地：RVA23 成为 64 位应用处理器的统一基线，Ubuntu 26.04 LTS（2026-04）是首个 RVA23 LTS，软硬件基线第一次对齐。[cite:11]
  • 服务器平台标准化：RISC-V Server Platform Specification v1.0 于 2026 年批准，补齐了启动/发现/中断/虚拟化等服务器“公共能力”。[cite:12]

目标客户与场景（推断，中等置信度）：

  • 国内信创/自主可控替换试点（党政、运营商、能源等）
  • 边缘与分布式 AI 推理节点（低功耗、高能效诉求）
  • 云原生轻量负载、数据库（已见 YashanDB 等国产数据库在峰会站台）
  • 与香山营企业（蓝芯算力、奕斯伟等）形成国产 RISC-V 服务器集群生态

  • 性能维度：V100（16.5/GHz，SPEC2006）已进入 RISC-V 第一梯队，与达摩院 C930（~15–17）同档，但落后 Tenstorrent Ascalon（>22）。[cite:7][cite:13][cite:17]

2.4 那么 V100 到底强在哪？——四条可辩护的优势

  1. “端—云”全栈打通的能力，是蓝芯目前不具备的。进迭时空已有 K1/K3 端侧芯片 + 完整 SDK + 全球首个原生适配 Ubuntu 26.04 LTS 的 RISC-V 平台经验，V100 可复用同一软件栈与生态资产，做“同构端云一体”。[cite:8][cite:28]
  2. 自研 IP 覆盖面更广，定制与供货更可控。从 CPU 核（X60/X100/X200）、虚拟化 IP（IOMMU/AIA/IOPMP）到互联总线 N200 均为自研，对信创客户的“可定制 + 供应链自主”叙事更完整。[cite:9][cite:29]
  3. 偏“通用服务器 CPU”定位，通用算力密度上限更高。若 64 核属实的纯大核方案，其对外提供的通用 vCPU 供给可能优于 48 核异构的 LX500；对以数据库/虚拟化为主、AI 为辅的负载更友好。
  4. 香山开源根社区的“正统性”与品牌外溢。香山系（含蓝芯、奕斯伟等）共享同一开源底座，V100 作为峰会主论坛发布产品，获得的生态曝光与联盟资源更集中。[cite:7]
必须承认的短板：在“量产进度”“AI 算力（75 vs ~32 TOPS）”“头部客户绑定（联想/中国移动）”这三项上，蓝芯 LX500 当前领先 V100。因此“V100 的优势”不是全面领先，而是“通用算力密度 + 端云全栈 + 自研 IP 广度”这几个维度。

3.1 一句话概括三条路线

  • x86：生态与性能天花板最高，但“不可自主 + 价高”，正被国产化需求把份额往外挤。
  • ARM：能效/性价比的“甜蜜点”，云端已被大规模验证，是 x86 之外最现实的主流选择。
  • RISC-V：“开源 + 可定制 + 供应链自主”的长期主义，2026 年刚跨过“服务器可用”门槛，V100 是这一跨越的标志性产物。

够用性能 + 可用生态V100、香山昆明湖、C930（正在突破这一象限的上边界）
低性能 + 边缘场景嵌入式 RISC-V/ARM

V100 的价值不是“登顶高性能象限”，而是把 RISC-V 从右下角推进到“够用 + 可用”象限，并把整机做出来。

5. 我的判断：更看好谁

问题分三层，答案也分三层（避免一句“站队”掩盖真实差异）：

  1. 如果只谈“RISC-V 服务器芯片里谁最有戏落地”——我更看好 V100。
    理由：它比多数对手更早拿到“工程化闭环”——流片、2U 整机、开源生态、国产供应链、真实客户场景试点。对产业客户来说，“能买到、能装上、跑得起”往往比“跑分高 5 分”更重要。这也是进迭时空从 K1/K3（端侧）切到服务器（V100）的关键一跃。
  2. 如果谈“通用服务器/云主战场站谁”——1–2 年内我更看好 ARM，其次是 x86。
    RISC-V 的优势是“开源自主”，短板是“生态与调优”。企业换架构的成本极高，V100 更适合“增量场景”（信创、边缘、AI 推理、轻量云）而非“存量替换”。ARM（尤其国产鲲鹏/飞腾）在“能效 + 性价比 + 生态”的平衡上，仍是当下最现实的选择。
  3. 如果谈“RISC-V 的长期性能天花板”——我更看好 Ascalon、P870-D、Veyron V2 这类高端 IP，以及“香山”IP 的持续迭代。
    V100 是“落地派”的代表，Ascalon/SiFive 是“性能派”的代表。V100 的 16.5/GHz 已属第一梯队，但要追上 x86/ARM 与顶尖 RISC-V 核的单核绝对性能，仍需依赖下一次核迭代（香山 V3 目标 22 分/GHz）。[cite:13]

最终一句话：“短期看 ARM/x86，RISC-V 里短期看 V100 的落地、长期看香山与 Ascalon/SiFive 的天花板。” V100 是一次“把开源 RISC-V 真正变成服务器产品”的里程碑，值得看好；但把它当成“今天就替代 EPYC/Xeon”的答案，会高估它当下的成熟度。
